Kenapa login Discord?

API key dan User ID Roblox tersimpan di akunmu dan terisi sendiri di HP, laptop, atau warnet mana pun. Tanpa login pun semua fitur tetap bisa dipakai.

Discord hanya dipakai untuk mengenali akunmu, dan password Discord tidak pernah dilihat website ini. Saat login, Discord juga meminta alamat email akunmu. Pakai API key khusus dengan izin Assets saja.

Saat otomatis aktif, Amplify dihitung ulang tiap speed berubah supaya suara setelah dibalik di Roblox mendekati aslinya. Kamu tetap bisa geser manual: tambahannya ikut terbawa saat speed digeser. Volume ikut tersimpan di file, jadi di Roblox Volume tetap 1.

Script di Roblox 
sound.PlaybackSpeed = 0.5

Di Roblox, PlaybackSpeed ikut mengubah nada. Karena itu file di sini juga diubah dengan nada ikut berubah, supaya kebalikannya pas.

Tambah akun

Isi API key, akun dicek otomatis.

Buat key di Creator Dashboard, menu Open Cloud, API Keys. Pilih Assets, operasi Read dan Write. Untuk alamat IP, isi 0.0.0.0/0 (semua IP) atau biarkan Restrict IP mati. Key hanya dikirim ke Roblox. Satu akun Discord bisa menyimpan sampai 3 akun Roblox.
